# Getting started with Cursor

This file is for **practice**. Open it in Preview so it looks like a real page, not raw text.

## Why Preview?

In the editor you see the source (`#`, `*`, `|`). In Preview you see:

- Headings as a table of contents
- Clickable [links](https://cursor.com/docs)
- Lists that are easy to scan
- Tables that line up

## Tiny checklist

1. Open this file in the editor.
2. Open Markdown Preview (steps below).
3. Compare the two views.

## Example table

| View | Best for |
| --- | --- |
| Editor | Writing and editing |
| Preview | Reading docs |

When the agent writes or edits a `.md` file, open Preview to read it.

## Practice loop

Use these phrases in order:

1. `Plan: …` — write or update `plan.md`, then wait
2. `OK implement` — make the change from the plan
3. `verify` — check the result and give you a short retest list
